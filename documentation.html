service-worker

extension/background/service-worker.js

BACKGROUND

Central ES-module background service worker. Orchestrates the full agent loop: reads page state from the content script, decides which perception pipeline to run (DOM-only, screenshot+OCR, or vision), runs the privacy sanitisation pipeline, invokes the Gemini LLM via agent.js, dispatches returned actions to the content script, and loops until complete or MAX_ITERATIONS is reached. Manages the Chrome offscreen document lifecycle.

CONSTANTS
NameValueDescription
MAX_ITERATIONS50Maximum agentic loop iterations before force-stopping.
VISION_KEYWORDSRegExpTriggers screenshot + vision model processing.
OCR_KEYWORDSRegExpTriggers screenshot + OCR processing.
CLICK_KEYWORDSRegExpIndicates a click/interaction task.
TYPE_KEYWORDSRegExpIndicates a type/fill task.
SCROLL_KEYWORDSRegExpIndicates scroll-only task - fast-paths to DOM-only perception.
MESSAGE HANDLERS
Message TypeParamsResponds With
RUN_TASK{ task: string, tabId?: number }{ success, answer, actions, privacy, steps }
CANCEL_TASK-{ success: true }
SET_SERVER_URL{ url: string }{ success: true, serverUrl: string }
GET_STATUS-{ serverUrl: string, offscreen: boolean }
CHECK_SERVER-{ success: true, online: true }
PRELOAD_MODELS-{ success: true } | { success: false, error }
FUNCTIONS
FunctionParamsReturnsDescription
getPerceptionPlan privatetask, pageStatePerceptionPlanKeyword-heuristic router. Defaults screenshot and vision to true; fast-paths scroll commands to DOM-only.
ensureOffscreen private-Promise<void>Creates the offscreen document if not already created. Idempotent via offscreenCreated flag.
handleTask privatetask, tabId?Promise<TaskResult>Core agentic loop. Runs perception + privacy, calls runAgent() up to MAX_ITERATIONS, dispatches actions to content script, prevents infinite loops via action de-duplication.

agent

extension/agent/agent.js

AGENT

ES module that communicates with the Gemini API (gemini-2.0-flash-lite) to determine the next browser action. Accepts task, page state, optional base64 screenshot, and action history. Returns structured JSON with answer, actions[], and reasoning. Hard-caps responses to 3 actions maximum per call. Uses temperature: 0.0 for deterministic outputs.

FUNCTIONS
FunctionParamsReturnsDescription
buildPrompt privatetask, pageState, actionHistory, retryReasonstringBuilds the user-turn prompt. Includes numbered action history with success/fail icons, current URL/title, interactive elements table, and page text extracts.
runAgent exportedapiKey, task, pageState, visualContextBase64, actionHistory, retryReasonPromise<{ answer, actions, reasoning }>POSTs to Gemini v1beta generateContent with response_mime_type: "application/json". Throws on HTTP error or JSON parse failure.

content / dom-collector

extension/content/dom-collector.js

CONTENT

Content-script IIFE that queries the live DOM for all interactive and media elements visible in the current viewport. Assigns stable integer IDs to elements, stores references in BA.elementMap for later action execution. Hard-caps output at 150 elements sorted top-to-bottom.

BA.MEDIA_SELstring'img, video, canvas, svg, iframe, object, embed'
FUNCTIONS
FunctionParamsReturnsDescription
BA.collectElements exported-ElementDescriptor[]Clears and rebuilds BA.elementMap. Each descriptor: { id, tag, type, text, ariaLabel, placeholder, bbox, visible, value, href, src, name, inputType, checked, disabled }.

content / action-executor

extension/content/action-executor.js

CONTENT

Full-featured content-script IIFE action executor. Handles all 8 action types. Critically supports both standard input/textarea and contenteditable elements (WhatsApp, Gmail, Notion) by using document.execCommand and native value setters to fire React/Vue synthetic events correctly.

ACTION TYPES
click

Focuses, calls el.click(), dispatches mousedown/mouseup/click.

type

Calls typeIntoElement - supports standard and contenteditable inputs.

typeAndSubmit

typeIntoElement then setTimeout(pressEnter, 100).

scroll

Scrolls element if scrollable, else finds largest scrollable ancestor.

select

Sets el.value and fires change event.

navigate

Sets window.location.href.

pressKey

Dispatches keydown+keyup on element or document.activeElement.

hover

Focuses element, dispatches mouseenter/mouseover/mousemove.

KEY FUNCTIONS
FunctionParamsReturnsDescription
BA.executeAction exportedaction: Action{ success, ... }Main dispatcher. Returns { success: false, error } on unknown type or thrown exception.
typeIntoElement privateel, textvoidFor contenteditable: uses document.execCommand('insertText') + per-character key events. For standard inputs: uses native value setter so React onChange fires.
pressEnter privateelvoidDispatches keydown/keypress/keyup with key='Enter', keyCode=13.
getElement privateid: numberHTMLElementLooks up ID in BA.elementMap. Throws if missing.

perception / router

extension/perception/router.js

PERCEPTION

ES module that analyses the user task and current PageState to produce a PerceptionPlan - a declarative decision on which perception modules to activate. Avoids expensive OCR/Vision inference when a simple DOM read suffices. Note: service-worker.js contains its own inline copy of this logic with different defaults that takes precedence.

FUNCTIONS
FunctionParamsReturnsDescription
getPerceptionPlan exportedtask, pageState{ needsDOM, needsScreenshot, needsOCR, needsVision, cropRegion, reasoning }Priority routing: (1) click/type/scroll without vision keywords -> DOM only. (2) VISION_KEYWORDS -> screenshot+vision. (3) OCR_KEYWORDS with images -> screenshot+OCR. (4) Default -> DOM only.

privacy / pii-detector

extension/privacy/pii-detector.js

PRIVACY

ES module for purely local, in-browser PII detection in text strings and DOM element descriptors. All processing is regex-based - zero network calls. Detects global and India-specific PII types.

CONSTANTS
NameDescription
PATTERNSNamed regex patterns: EMAIL, PHONE, CREDIT_CARD, SSN, AADHAAR (12-digit Indian national ID), PAN (Indian tax ID), IP_ADDRESS.
SENSITIVE_FIELD_TYPES['password', 'email', 'tel', 'cc-number', 'cc-exp', 'cc-csc', 'credit-card']
SENSITIVE_NAMES/passw|secret|token|api.?key|ssn|aadhaar|pan.?card|cvv|cvc/i - matched against element name + placeholder + ariaLabel.
FUNCTIONS
FunctionParamsReturnsDescription
detectTextPII exportedtext: stringArray<{ type, match, index }>Scans text against all PATTERNS. Returns all hits with PII type, matched string, and character index.
isSensitiveField exportedelement: ElementDescriptorbooleanReturns true if element.inputType is in SENSITIVE_FIELD_TYPES, or name/placeholder/ariaLabel matches SENSITIVE_NAMES.
scanPageState exportedpageState: PageState{ processed: true, redactedCount, regions: PrivacyRegion[] }Iterates all elements (field sensitivity + text PII) and all text blocks. Accumulates a flat regions array and total count.

privacy / redactor

extension/privacy/redactor.js

PRIVACY

ES module that produces a sanitised deep-clone of a PageState by replacing detected PII with labelled placeholders. Also provides Canvas-based image region redaction. Note: redactImageRegions requires OffscreenCanvas - must run in the offscreen document context.

CONSTANTS
NameValues
REDACT_LABELS{ EMAIL: '[REDACTED_EMAIL]', PHONE: '[REDACTED_PHONE]', CREDIT_CARD: '[REDACTED_CC]', SSN: '[REDACTED_SSN]', AADHAAR: '[REDACTED_AADHAAR]', PAN: '[REDACTED_PAN]', IP_ADDRESS: '[REDACTED_IP]', SENSITIVE_FIELD: '[REDACTED]' }
FUNCTIONS
FunctionParamsReturnsDescription
redactPageState exportedpageState: PageState{ sanitizedState, privacyMeta }Deep-clones via JSON round-trip, runs scanPageState(), applies redactString() to all element text/value/placeholder fields. Sensitive fields get '[REDACTED]'.
redactString privatestr: stringstringCalls detectTextPII, sorts hits descending by index, replaces each match in-place to avoid position shifts.
redactImageRegions exporteddataUrl: string, regions: PrivacyRegion[]Promise<string>Draws image onto OffscreenCanvas, fills each region bbox with black, draws a red type label. Requires offscreen document context.

offscreen / offscreen.src

extension/offscreen/offscreen.src.js

OFFSCREEN - ML ENGINE

Bundled (webpack) ES module running all local ML inference inside the Chrome offscreen document. Hosts: (1) YOLOS-tiny object detection via @huggingface/transformers for face/person privacy and vision queries; (2) Tesseract.js for OCR; (3) Canvas API for image cropping and visual redaction. Both ML models are lazily loaded and cached via the Transformers.js browser cache.

CONSTANTS

env.allowLocalModelsfalseForces model downloads from HuggingFace Hub.
env.useBrowserCachetrueCaches downloaded models in browser storage.
STATUS{ objectDetection, ocr }Lifecycle state for both models: 'idle' | 'loading' | 'ready' | 'error'.
PII_PATTERNSArray<{ type, regex }>Internal PII regex set for OCR scanning: EMAIL, PHONE, CREDIT_CARD, AADHAAR, PAN, SSN.
