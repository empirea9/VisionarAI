SUPPORT / DOCS

Frequently Asked
Questions

PRIVACY Why run VisionarAI locally?
Sending raw screenshots to cloud LLMs exposes passwords, banking details, and private chats to third-party servers. Running local ML models ensures your data is scrubbed and never leaves your device unredacted — compliant with GDPR, DPDP Act, and HIPAA by design.
TECH How does the "Visual Firewall" work?
VisionarAI runs YOLOS-tiny (object detection) and Tesseract OCR entirely inside your browser via WebAssembly. It detects sensitive text and human faces, then uses the HTML5 Canvas API to physically overwrite those pixels with black boxes — before the image is ever sent to the cloud LLM.
PERF Does this slow down my browsing?
No. VisionarAI uses Chrome's Offscreen Document API to run heavy ML inference in a completely isolated background thread. Your active tab and browsing session remain perfectly smooth and responsive at all times.
PRIVACY Can it still detect faces if I ask it to?
Yes. The face-blurring is context-aware. If you explicitly ask a question like "who is on my screen-, the extension temporarily bypasses the face redaction step so the AI can answer accurately. Privacy is default — not mandatory.
OPEN SOURCE Is this open-source? Can I contribute?
Absolutely. VisionarAI is fully open-source and available on GitHub. You can review the full source, report issues, or submit pull requests. Contributions are welcome.
